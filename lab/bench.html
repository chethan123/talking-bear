Silero and worklet DSP timing

X-V2 (plan §5): the Silero TS port's time per 512-sample frame (32 ms of 16 kHz audio), in a Worker, with onnxruntime-web (wasm, 1 thread) for comparison. Gate: silero-ts p95 ≤ 8 ms. worklet-dsp times the capture worklet's high-pass, ring buffer and 16 kHz decimator per 128-frame quantum (plan §4.10: p99 ≤ 50 µs), since the worklet itself has no performance.

silero-ort needs the pinned ONNX file: run pnpm silero:fetch once (it caches the file in .cache/silero/, which pnpm dev serves). Without it the run reports “ORT unavailable” and the others continue.

Thermals: on D1, capture adb shell dumpsys thermalservice before and after the 10-min run (plan §4.10: thermal status ≤ LIGHT).

The input is synthetic (alternating 2 s of pink noise at −40 dBFS and 2 s of a synthetic vowel). Nothing is captured or stored; Copy log copies text only.
