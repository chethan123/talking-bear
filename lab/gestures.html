Gestures: labelled pointer traces

X-A7 (plan §5): at least 5 people, children included, each doing at least 20 prompted trials. For each person, set an anonymous participant number (P1, P2, …, never a name) and the age group, then let them do what each prompt asks, on the outlined region: a tap, a long-press (press and hold), a pet (stroke the head) or a tickle (scrub the belly, or tap it quickly). The prompts come in a random order, each gesture once in every four trials. The prompt and the recogniser's gestures show below the bear.

A trial records every pointer sample the app's pointer adapter feeds the recogniser (each coalesced move and the frame ticks included), from the first touch until 600 ms after the last finger lifts; a touch within those 600 ms continues the same trial. The bear is drawn once, in the neutral pose with no animation, so the regions never move. Lab pages have no CSS sizing that fits the bear's aspect, so the canvas's backing store has its CSS size, and the bear looks soft on a high-DPR screen.

Export saves this participant's trials as one JSON file, gestures-P<n>-<UTC time>.json, with the canvas size and device pixel ratio; New participant clears them once exported. Score the files with node scripts/gesture-eval.ts <files…> --min 0.9 (docs/lab.md).

Privacy (plan Q2): pointer coordinates and times only, with the participant number and age group. This page never opens the microphone or plays any sound, stores nothing in the browser, and exports only when Export is pressed.
