# Research spikes (throwaway)

Code written during planning (2026-09-26/27) to check claims in [`docs/plan.md`](../../plan.md) before committing to them.

**This is not application code.**

- Nothing under `src/` may import from here.
- M1 must add `docs/research/**` to the oxlint, tsconfig, Vitest and `.dockerignore` excludes.
- Delete each spike once the production module it informed has landed. The table says which.

## Rules these files follow

- **No real-voice audio is committed** (plan Q2). The VAD spike runs on two upstream Silero test clips; you fetch them yourself by cloning `silero-vad` (MIT).
- **No third-party code or binaries are committed.** Dependencies come from `npm install`. `ss_module.cjs` is regenerated by a script. Models and test audio come from the upstream clone. `.gitignore` covers the generated files.
- **Numbers are sandbox numbers, not phone numbers:** headless Chromium 141 (Playwright 1.56), Node 22, and a 2.1 GHz Xeon VM. The plan tags them `[E]`.
- **The code is as it was run,** apart from paths. Sandbox-only absolute paths (`/opt/...`, scratch directories) were replaced with normal package imports or a local `./silero-vad` clone.
- **Playwright:** install `playwright` in each folder, or point `NODE_PATH` at a global install. Don't run `playwright install` where Chromium is already provided.
